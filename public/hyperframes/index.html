HTML jadi video.

Video 8 detik ukuran 1080x1920 yang seluruhnya dibuat dari satu file HTML, lalu direkam jadi MP4 oleh HyperFrames. Lengkap dengan prompt untuk membuatnya dari nol pakai AI agent.

Download starter (.zip, 139 KB) Lihat isinya di GitHub

Starter ini dipakai di laptop. Kalau kamu buka dari HP, kirim link ini ke dirimu sendiri dulu, lalu buka di laptop.

Isi paket

  • index.html: videonya. 3 scene, teks, warna, dan animasi GSAP ada di satu file.
  • PROMPT.md: prompt untuk membuat video serupa dari nol, plus 3 variasi (ganti teks, ganti warna, tambah scene).
  • BACA-DULU.md: panduan lengkap, syarat, dan batasan.
  • Font Inter dan JetBrains Mono (lisensi OFL) dan GSAP disimpan lokal, jadi render tidak butuh internet.

Cara pakai

  1. Unzip, lalu buka terminal di folder hyperframes-video-starter.
  2. Cek syaratnya (Node.js 22+ dan FFmpeg): npx hyperframes doctor
  3. Lihat videonya di browser: npx hyperframes preview
  4. Render jadi MP4 di folder renders/: npx hyperframes render
  5. Mau ubah? Buka AI agent (misalnya Claude Code) di folder itu dan tempel salah satu prompt dari PROMPT.md.

Yang perlu kamu tahu

  • Ini bukan editor drag-and-drop seperti CapCut atau Canva. Videonya adalah kode, diubah sendiri atau lewat AI agent.
  • Butuh terminal. Internet hanya perlu saat pertama kali, untuk mengunduh HyperFrames dan browser perekamnya.
  • Starter ini belum memakai audio.
  • AI agent bisa salah. Jalankan npx hyperframes check dan lihat preview sebelum render.
